# Fundamentos de Linguagem Python - Do Básico a Aplicações de IA

Este repositório documenta minha jornada de 96 horas de treinamento intensivo na **Data Science Academy (DSA)**. O projeto abrange desde os pilares da programação até a construção de agentes inteligentes e modelos de Deep Learning.

## 🚀 Tecnologias e Conceitos Explorados
- **Linguagem:** Python 3.x aplicada à Ciência de Dados e IA.
- **Análise de Dados:** NumPy, Pandas, Matplotlib e Statsmodels.
- **Machine Learning & Deep Learning:** Scikit-Learn e PyTorch.
- **IA Generativa:** LLMs, RAG (Retrieval-Augmented Generation), LangChain e CrewAI.
- **Deploy:** Criação de Data Apps interativos com Streamlit e conceitos de MLOps.

## 📂 Estrutura do Portfólio
O curso é composto por 10 mini-projetos práticos e 3 estudos de caso principais:

- **Lógica e POO:** Desenvolvimento de sistemas bancários e games em Python.
- **Análise Estatística:** Projetos de churn, marketing e análise de vendas e-commerce.
- **Inteligência Artificial:** Classificação de imagens, análise de sentimentos e construção de LLMs do zero.
- **Agentes Autônomos:** Deploy de aplicações multi-agentes para planejamento de viagens e assistência jurídica.
